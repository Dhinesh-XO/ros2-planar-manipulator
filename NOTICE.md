# Source provenance and evaluation use

The supplied starter package declares "Proprietary — for evaluation use only".
This repository preserves that declaration and makes no new blanket open-source
license grant for the starter or assignment. The supplied `planar_arm.py` is
unchanged. A private assessment repository is the intended handover format
unless the starter's owner has authorized broader publication.

One CSV/JSONL helper is reused from the robotics telemetry suite with its
declared Apache-2.0 license and attribution. See the
[third-party notice](src/planar_arm_control/third_party/NOTICE.md) and
[license text](src/planar_arm_control/third_party/Apache-2.0.txt).
That helper's license does not relicense the rest of this repository.

The assessment permits AI assistance. The Git history preserves implementation
milestones and their recorded authorship; it has not been rewritten to imply
different authorship. The candidate remains responsible for understanding the
work and reviewing the written answers in their own words.
